# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in TeachDiffusion, please report it responsibly.

**Do NOT open a public issue for security vulnerabilities.**

Instead, please email the maintainers directly or use GitHub's private vulnerability reporting feature.

## Scope

TeachDiffusion processes video data and interacts with external APIs. Security concerns may include:
- API key exposure in logs or outputs
- Unsafe file handling in the dataset pipeline
- Dependency vulnerabilities

## Response

We will acknowledge security reports within 48 hours and provide a fix timeline within 7 days.
